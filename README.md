# 🪔 Modak Catch

A fun and festive browser game inspired by Ganesh Chaturthi.

In **Modak Catch**, players control a bowl and catch falling modaks while trying to achieve the highest score. As the game progresses, the falling objects become faster and the challenge increases.

## 🎮 Play the Game

**Live Demo:** https://modak-catch.pages.dev/

## ✨ Features

- 🍥 Catch falling modaks to increase your score
- ✨ Golden Modak bonus worth extra points
- ❤️ 3 lives per game
- 📈 Increasing difficulty
- 🏆 Online leaderboard
- 👤 Player name system
- 🔄 Replay and change-name options
- 📱 Mobile-friendly controls
- 💻 Keyboard controls for desktop
- 🎨 Festive Ganesh Chaturthi-inspired design
- ♾️ Endless gameplay

🕹️ How to Play

Mobile

- Tap the **left side** of the screen to move left.
- Tap the **right side** of the screen to move right.
- Catch the falling modaks with the bowl.

Laptop / Desktop

- **Left Arrow / A** → Move left
- **Right Arrow / D** → Move right

### Scoring

| Object | Points |
|---|---:|
| Normal Modak | +10 |
| Golden Modak | +50 |

Missing a falling object costs **one life**.

The game ends when all 3 lives are lost.

🏆 Leaderboard

Players can save their best score to the online leaderboard after completing a game.

The leaderboard displays the highest scores so players can compete for the top position.
